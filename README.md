# Interactive To-Do List & Task Tracker

## About the Project

The Interactive To-Do List & Task Tracker is a web-based application
developed to manage daily tasks easily.

## Features

- Add new tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks
- View all tasks
- View pending tasks
- View completed tasks
- Task statistics
- Responsive design

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## Project Structure

- index.html - Structure and user interface
- script.js - Task functionality
- README.md - Project documentation

## How It Works

Users can enter a task and click the Add Task button.
Tasks can then be completed, edited or deleted.

## Deployment

The project is deployed using GitHub Pages.
